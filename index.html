    ℹ️ About Palm ID

    Palm ID uses Claude AI (claude-opus-4-6) to identify palm tree species in South Florida. Photos are sent to the Anthropic API for analysis. Image data is not stored on Anthropic's servers. For best results, photograph the full trunk and fronds in good lighting. Including crownshaft, frond shape, and trunk texture significantly improves accuracy. Version 1.0.0 · Made for South Florida 🌴
